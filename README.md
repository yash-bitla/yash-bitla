# Hi, I'm Yash

I'm a software engineer at Age Bold, where I build healthcare systems that connect Medicare members to preventive care.

## What I work on

Most of my work is on large-scale backend systems that millions of people use, and on the ML systems built on top of them. On the backend side, I build services that stay fast and correct as the load grows. On the ML side, I build the serving stack that turns a model into real-time, personalized recommendations under a tight latency budget. Most recently I have been building GPT-based recommendation models.

## What I'm interested in

I like the place where machine learning meets software engineering: the work it takes to turn a model into a system that people can depend on. That means serving under a latency budget, backend systems that stay correct at scale, evaluation that matches what users experience, and feedback loops that make the model better over time.
